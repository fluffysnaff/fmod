FMod is an addon for [Meteor Client](https://meteorclient.com/), a Minecraft client mod. It adds modules for finding stashes and bases, following trails, flying long distances with an elytra, and hiding your coordinates on stream. FMod started as a project inspired by LiveOverflow's Minecraft modding series, and it still has the teleport and clip commands from that time.

## What you can do with it

- **Search an anarchy server for stashes.** SearchArea moves you through a rectangle or an endless spiral. BetterStashFinder records chests and other storage it finds in loaded chunks, saves them as CSV and JSON files, and can mark them on your map.
- **Follow a trail to a base.** OldChunkNotifier tells you when you reach old chunks. These are areas first generated by an older Minecraft version, so players were there long ago. TrailFollower uses Baritone to follow a line of old chunks across the map. TrailMaker lets you draw a route with XaeroPlus highlights and then follow it.
- **Fly long distances with less work.** ElytraFlyPlusPlus uses Baritone to pass obstacles on highways. Pitch40Util turns pitch 40 flight back on after you reconnect to 2b2t. AFKVanillaFly holds level flight with fireworks.
- **Record or stream without showing where you are.** coord-hider hides the F3 position lines, Meteor HUD coordinates, and coordinate text in chat and on the HUD.
- **Know what happens while you are away.** AutoLogPlus adds more reasons to log out. DiscordNotifs and OldChunkNotifier can send messages to your own Discord webhook. Nothing is sent until you enter a webhook URL.

FMod also includes ChestIndex, HighlightOldLava, VanityESP, AutoPortal, AutoEXPPlus, GrimAirPlace, NoJumpDelay, NoTextureRotations, FrameDupe, two HUD elements, and the `.tp`, `.autoclip`, `.shclip`, `.dclip` and `.clubmate` commands. [All features](docs/FEATURES.md) describes each one.

## Install

1. Install [Meteor Client](https://meteorclient.com/download) for Minecraft 26.3. You need Fabric Loader 0.19.5 or newer and Java 25 or newer.
2. Download the `fmod-<version>.jar` file from the [dev build](https://github.com/fluffysnaff/fmod/releases/tag/snapshot). It is built automatically from the `main` branch.
3. Put the jar in your `.minecraft/mods` folder, next to the Meteor Client jar.
4. Start Minecraft with your Fabric profile. Open Meteor's menu (Right Shift by default) and find the modules in the **FMod** category. Commands start with `.`.

The map and trail modules need Xaero's World Map, Xaero's Minimap and XaeroPlus. TrailFollower and ElytraFlyPlusPlus also need Baritone. FMod loads without these mods, but the modules that need them do not appear. [Optional mods](docs/FEATURES.md#optional-mods) lists the tested versions.

## Before you use it

- coord-hider changes only the text on your screen. Network packets, saved routes, stash exports, logs, your clipboard and webhook messages keep your real coordinates. Maps and the world itself stay visible.
- Many servers do not allow client mods like Meteor. Read a server's rules before you use FMod on it.
- The v1.1.1 release on the Releases page is for an older Minecraft version and has different modules.

## Build from source

You need JDK 25. Set `JAVA_HOME` to it, then run:

```bash
git clone https://github.com/fluffysnaff/fmod.git
cd fmod
bash ./gradlew build
```

On Windows, run `.\gradlew.bat build` instead of the last line. The jar is written to `build/libs/`, for example `build/libs/fmod-0.2.0.jar`.
